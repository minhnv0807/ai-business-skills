# SEO Growth Playbook

## 90 ngay mac dinh

| Giai doan | Viec chinh | Output |
|-----------|------------|--------|
| Ngay 1-14 | Audit technical + Search Console + top pages | Fix list uu tien |
| Ngay 15-30 | Keyword map + page roadmap | 10-30 page backlog |
| Ngay 31-60 | Publish BOFU/MOFU + schema | Pages co CTA |
| Ngay 61-75 | Directory/backlink batch | Submission tracker |
| Ngay 76-90 | Refresh, internal link, measure | Report + next sprint |

## pSEO khi nao nen lam

Nen lam khi co:

- Dataset that: locations, integrations, templates, use cases, products, categories.
- Search pattern lap lai: "[tool] alternative", "[service] in [city]", "[template] for [role]".
- Template page tao gia tri rieng cho tung bien.

Khong nen lam khi:

- Chi thay keyword volume nhung khong co data.
- Page gan nhu giong nhau.
- Khong co nguon luc cap nhat va internal link.

## AI SEO content pattern

Moi bai/page nen co:

- TL;DR dau trang.
- Dinh nghia ngan.
- Bang so sanh.
- Step-by-step.
- FAQ.
- Nguon/chung cu.
- Last updated.
- Author/entity.

## Directory tracker columns

Dung CSV hoac sheet:

`directory, tier, url, category, asset_needed, submitted_date, status, live_url, backlink_type, lead_source_tag, notes`

## Do luong

| Muc tieu | Metric |
|----------|--------|
| Index | indexed pages, crawl errors |
| Traffic | organic sessions, clicks, impressions |
| Quality | CTR, engaged sessions, conversion rate |
| AI visibility | AI mentions/citations for target queries |
| Authority | referring domains, branded search, reviews |
