# Phan 1 — Content Analytics

## 1. 3 cau hoi can tra loi moi tuan

1. Content nao dang hoat dong tot nhat? → **Nhan ban**.
2. Content nao dang kem? → **Dung hoac cai thien**.
3. Format / angle nao nen test tiep? → **Len ke hoach**.

Neu review tuan khong tra loi duoc 3 cau nay thi buoi review khong tao ra quyet dinh nao.

## 2. Metric theo kenh organic

### TikTok / Reels

| Metric | Benchmark tot |
|---|---|
| Watch time (%) | > 50% |
| Completion rate | > 30% |
| Shares | > 1% views |
| Follows tu video | > 0.5% views |

**Chi so quan trong nhat: Watch time %** — thuat toan rank chu yeu dua tren chi so nay, khong phai luot like.

### Facebook / Threads

| Metric | Benchmark tot |
|---|---|
| Engagement Rate | > 3% |
| Shares | Cang nhieu cang tot — tin hieu manh nhat |
| Comments | Comment that co gia tri hon like |

## 3. Content Win / Lose Framework

**Content Win = dat >= 2 trong 3 tieu chi:**

1. ER cao hon trung binh toi thieu 2x.
2. Dan den hanh dong cu the (DM, click, share).
3. Nhan phan hoi tich cuc tu **dung tep** muc tieu.

**Phan tich hang thang:** lay Top 5 content win → tim pattern chung (format / angle / pillar / hook / timing) → nhan ban pattern do cho thang sau.

Luu y: content nhieu view nhung khong ra hanh dong va khong dung tep thi khong tinh la win.

## 4. Content-to-Revenue Attribution cho SME

| Cach | Trien khai |
|---|---|
| UTM Tracking | Gan UTM vao moi link → biet traffic den tu kenh/bai nao |
| Hoi truc tiep | "Biet den chung toi qua dau?" — dat trong form dang ky |
| Cohort analysis | KH inbox sau khi xem video nao? |
| Correlation | Noi dung nao dang → DM tang trong 24-48h sau? |

SME khong can attribution model phuc tap. 4 cach tren du de ra quyet dinh phan bo nguon luc content.

# Phan 2 — Performance Framework

## 1. Campaign Phases — 4 giai doan

### Phase 1 — TEASING (10-15% ngan sach)

- Thoi gian: 1-2 tuan | Objective: Reach / Video views | KPI: CPM, Reach, View rate.
- Viec lam: test 3-5 creative + 2-3 audience → doc so tu ngay 3 → loai bo nhom kem.

### Phase 2 — BUNG NHE (20-25% ngan sach)

- Thoi gian: 2-3 tuan | Objective: Messages / Leads | KPI: CPL, CPMess, CVR Lead.
- Viec lam: scale creative win tu Phase 1 + test landing page + bat dau nurture + retarget viewers.

### Phase 3 — BUNG MANH (40-50% ngan sach)

- Thoi gian: 2-4 tuan | Objective: Conversions | KPI: ROAS, CPO, Revenue.
- Viec lam: tang budget 20-30%/ngay (khong tang dot ngot) + retarget warm + monitor frequency.

### Phase 4 — DUY TRI (15-20% ngan sach)

- Thoi gian: 1-2 tuan | Objective: Retargeting | KPI: CVR retarget, CPO.

## 2. Budget Split (tham chieu SME Vietnam)

| Kenh | % ngan sach |
|---|---|
| Meta (FB + IG) | 60-70% |
| TikTok Ads | 20-30% |
| Google Ads | 0-10% |

**Trong Meta:**

| Muc tieu | % |
|---|---|
| Awareness | 10% |
| Traffic / Messages | 30% |
| Conversions | 50% |
| Retargeting | 10% |

## 3. Target Audience — 3 tang

| Tang | Nguon tep |
|---|---|
| Cold | Interest targeting + Demographic + Lookalike tu customer list |
| Warm | Website visitors + Video viewers 25-75% + Page engagers 180 ngay |
| Hot (Retarget) | LP visitors chua mua + Lead form chua submit + Inbox chua chot |

**Quy tac:**
- Audience size toi thieu cho cold: 100K-500K.
- Khong de overlap giua cac ad set — overlap lam day chi phi dau gia len.

## 4. Ket noi Content va Performance

Content win tren organic la nguon creative tot nhat cho ads: da duoc thi truong xac nhan, chi phi test thap. Quy trinh:

```
Content organic (do bang Win/Lose framework)
  → Top 3 content win → dua vao Phase 1 lam creative test
    → Creative win o Phase 1 → scale o Phase 2-3
      → Ket qua ads → feedback ve angle cho content thang sau
```
