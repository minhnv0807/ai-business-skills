# K-R1 — Market Research

> Cap nhat: 2026-07 | Tang: Research | Dung cho: Marketing Manager, Planner, Leader.
> SOP thuc thi lien quan: `skills/vi/08-nghien-cuu-doi-thu`, `51-audience-research`, `58-positioning`.

## 1. TAM / SAM / SOM Framework

| Khai niem | Dinh nghia |
|---|---|
| TAM (Total Available Market) | Tong quy mo thi truong toi da |
| SAM (Serviceable Available Market) | Tep co nhu cau ro & phu hop san pham |
| SOM (Serviceable Obtainable Market) | Tep co the tiep can trong 3-6 thang |

**Nguyen tac: luon bat dau tu SOM.** SME khong co nguon luc de danh TAM — chon dung SOM la quyet dinh chien luoc quan trong nhat cua giai doan dau.

### So cap (tu thu thap)

| Phuong phap | Phu hop khi |
|---|---|
| Khao sat online (Google Form) | Can so lieu dinh luong |
| Phong van sau 1:1 (10-15 nguoi) | Can insight dinh tinh |
| Seeding thu feedback trong group | Thieu ngan sach |
| Social listening (comment, review) | Can hieu ngon ngu that cua KH |

## 3. Research khi thieu du lieu — 5 cach chi phi thap

1. **Doc comment doi thu** → lay pain point & insight that, dung nguyen van ngon ngu KH.
2. **Seeding cau hoi trong group** → quan sat phan ung, dem so luong va sac thai phan hoi.
3. **Phong van 10 KH tieu bieu** → hoi ve **hanh vi da lam**, khong hoi **y kien se lam**.
4. **A/B test nho ngan sach 200-500K/ngay** → do xem message nao work truoc khi dau tu lon.
5. **Phan tich content viral cua doi thu** → tim angle KH dang quan tam va format dang an.

Ket qua cua 5 cach nay khong thay the duoc research chuyen nghiep, nhung du de ra quyet dinh cho vong test dau tien.

## 4. SOM Scoring — thang 45 diem

| Nhom tieu chi | Cau hoi | Diem (1-5) |
|---|---|---|
| Nhu cau thi truong | Noi dau ro rang, dang gia tang? | |
| | Tan suat tim kiem, thao luan cao? | |
| | Thi truong ben vung, khong phai trend nhat thoi? | |
| Muc do canh tranh | Co nhieu doi thu lon khong? | |
| | Ho da phu kin cac kenh chua? | |
| | Co ngach nho chua ai truyen thong ro? | |
| Kha nang tiep can | Co san kenh/tep phu hop? | |
| | Test MVP voi chi phi thap duoc khong? | |
| | KH de ra quyet dinh? | |

**Quyet dinh:** >= 30 diem → test ngay | 25-30 → can nhac, thu nghiem gioi han | < 25 → xem lai tep hoac doi ngach.

## 5. Competitor Mapping — 3 tang doi thu

| Tang | Dinh nghia | Cach phan tich |
|---|---|---|
| Truc tiep | Cung phan khuc KH + cung tinh chat san pham | So sanh: gia, positioning, kenh, creative |
| Gian tiep | Khac tinh chat nhung co the thay the | KH dang lam gi thay vi dung san pham cua ban? |
| Thu cap | Cung tinh chat san pham — khac phan khuc gia | Hieu ceiling/floor gia cua nganh |

Voi moi doi thu truc tiep, toi thieu ghi lai: cau message chinh, offer dang chay, kenh chu luc, tan suat dang, va 3 creative dang chay lau nhat (dau hieu creative win).

## 6. Checklist Market Research — 5 buoc

```
Buoc 1: TAM / SAM / SOM
Buoc 2: Persona (xem K-R2)
Buoc 3: Competitor mapping 3 tang
Buoc 4: SOM scoring 45 diem
Buoc 5: Tong hop insight — Top 3 tep KH / Top 3 co hoi / Top 3 rui ro
```

Output cuoi cung phai tra loi duoc 1 cau: **tep nao danh truoc, bang thong diep gi, tren kenh nao.** Neu chua tra loi duoc thi research chua xong.
