### Quy tac upload

1. **Knowledge truoc, skill sau.** Nap tu duy nen tang truoc de AI hieu context, roi moi them SOP.
2. **Khong upload trung.** Mot file chi nen nam o 1-2 project — trung nhieu lam loang ket qua truy xuat.
3. **Uu tien file hay dung.** Neu 1 file khong duoc dung trong 1 thang, thay bang file khac.
4. **Cap nhat dong bo.** Khi sua file trong `knowledge/`, upload lai vao TAT CA project dang dung file do.
5. **Brand Hub rieng.** Context rieng cua doanh nghiep (`.agents/product-marketing-context.md`, brand guideline) luon upload vao moi project — day la nguon su that, khong phai knowledge chung.
